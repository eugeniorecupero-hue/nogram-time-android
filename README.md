# NoGram Time - Android App

Take control of your Instagram usage with blocking functionality and diagnostics.

## Features
- Instagram blocking toggle
- Comprehensive diagnostics system
- Material Design 3 UI
- Android 14 compliant

## Build
This project uses GitHub Actions for automated APK builds.

Push to main branch to trigger a build. Download the APK from Actions > Artifacts.

## Tech Stack
- Kotlin 1.9.24
- AGP 8.5.0
- Min SDK 24, Target SDK 34
- Material Design 3
